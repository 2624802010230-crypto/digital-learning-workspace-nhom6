💡 Điều nhóm học được
-Kỹ năng làm việc nhóm số:Nâng cao khả năng phối hợp trực tuyến, phân chia công việc minh bạch và đồng bộ tài liệu hiệu quả trên nền tảng đám mây.
-Tư duy tổ chức thông tin:Hiểu cách sắp xếp cây thư mục khoa học, thiết lập quyền riêng tư và bảo mật dữ liệu cá nhân cũng như dữ liệu nhóm.
-Làm quen với môi trường chuyên nghiệp:Bước đầu biết cách sử dụng GitHub để quản lý tài liệu dự án thông qua file `README.md` giống như một lập trình viên thực thụ dù chưa cần viết mã nguồn code.
-Ý thức sử dụng AI có trách nhiệm:Biết cách đặt prompt hiệu quả, kiểm chứng thông tin do AI cung cấp để tránh sai sót và hiểu rõ nguyên tắc chống đạo văn.
